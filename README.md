# SpaceShooter 🚀

**SpaceShooter** to wciągająca gra w stylu klasycznych strzelanek kosmicznych, w której sterujesz statkiem kosmicznym, unikając i eliminując wrogów.

---

## Funkcje gry

- Sterowanie statkiem kosmicznym za pomocą klawiatury
- Strzelanie do wrogów
- Efekty dźwiękowe i muzyka w tle
- Prosta, ale wciągająca mechanika gry

---

## Instalacja

Aby uruchomić grę, wykonaj poniższe kroki:

1. **Sklonuj repozytorium:**
git clone https://github.com/MariuszOwczarek/space_shooter.git
cd space_shooter-master

2.**Utwórz i aktywuj środowisko wirtualne (opcjonalnie, ale zalecane)**
Na systemie Linux/macOS:
python3 -m venv venv
source venv/bin/activate

Na Windows:
python -m venv venv
venv\Scripts\activate

3.**Zainstaluj wymagane pakiety**
pip install -r requirements.txt

4.**Uruchom gre**
python main.py

5.**Sterowanie**
A/W/S/D – poruszanie statkiem
Spacja – strzelanie
